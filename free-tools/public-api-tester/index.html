Public API tester

Paste a JSON or XML API URL and see it the way an analytics tool will: which part of the response holds the rows, what each column’s type is, what’s missing or suspicious — plus a CSV export and the exact settings to connect it as a live dataset.

Free, no sign-up. Your browser calls the API directly — nothing goes through a QuantumLayers server, and nothing is stored.

Or paste a response body / open a saved file (JSON, XML or CSV)

Use this when an API blocks browser calls (no CORS): open the URL in a new tab, copy what it returns, paste it here.

What this checks

  • Where the rows are. Most APIs wrap their data — {"data": [...]}, [paging, rows], columnar arrays, maps keyed by date, SDMX. The tester finds the table the same way QuantumLayers’ REST connector does, shows the response path it used, and suggests a better one when the automatic pick looks wrong.
  • Column types. Each column is typed with QuantumLayers’ own rules (integer, float, date, datetime, text) — including treating ID and postcode-like columns as text, not numbers.
  • Data quality. Missing values, sentinel codes like -999, numbers delivered as strings, columns that are entirely empty, list indexes flattened into dozens of columns, and signs that you only got the first page of results.
  • Whether a browser can call it. If the API doesn’t send CORS headers, browsers can’t read it directly. That doesn’t matter for a server-side connector — paste the body to test it anyway.
